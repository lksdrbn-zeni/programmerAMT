# Psychology Communication Bootstrap Full Program

Тема WordPress для дипломного проекта «Разработка сайта по учебной дисциплине “Психология общения”».

## Что изменено

- Наполнение сайта сделано по рабочей программе ОГСЭ.03 «Психология общения».
- Добавлен тематический план на 50 часов: разделы, темы, уроки, содержание, часы, компетенции.
- Добавлены карточки всех тем и практических занятий.
- Добавлены результаты освоения: знания, умения, формы контроля.
- Добавлен тест из 20 вопросов по всей программе.
- Статичная псевдо-админка удалена. Управление материалами и вопросами выполняется через WordPress.

## Установка темы

1. Войдите в админ-панель WordPress: `ваш-сайт.ru/wp-admin`.
2. Перейдите: **Внешний вид → Темы → Добавить новую → Загрузить тему**.
3. Выберите архив `psychology-bootstrap-wp-full-program.zip`.
4. Нажмите **Установить**, затем **Активировать**.
5. После активации появятся разделы: **Психология: материалы** и **Психология: тесты**.
6. Откройте главную страницу сайта и проверьте тематический план, материалы и тест.

## Публикация в интернет

1. Купите домен и хостинг с поддержкой PHP 8+ и MySQL/MariaDB.
2. Установите WordPress через панель хостинга.
3. Войдите в админку WordPress.
4. Загрузите тему через раздел **Внешний вид → Темы**.
5. Активируйте тему.
6. В разделе **Настройки → Постоянные ссылки** выберите вариант «Название записи» и нажмите **Сохранить**.
7. В разделе **Настройки → Чтение** поставьте главную страницу сайта как главную, если WordPress попросит это сделать.
8. Проверьте сайт на телефоне и компьютере.
9. Создайте отдельного пользователя для преподавателя с ролью «Редактор» или «Администратор».
10. Сделайте резервную копию сайта после настройки.
